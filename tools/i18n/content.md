# Timeless Living — English terminology

英語版サイトで使う語の基準。翻訳のたびにここを見る。

調べたのは2系統。**A: 日本の物件を英語で書くときの語彙**（在日外国人が他所で見慣れている言い方）と、
**B: 素材と仕事の語彙**（英国の改修系の設計事務所・建築メディアが使う言い方）。
Aは正確さ、Bは質感を担当する。混ぜて使わない。片方の語彙でもう片方を書くと、
不動産広告か詩のどちらかになる。

判定記号 — ✓ 現状のままでよい / △ 要検討 / ✗ 要修正 / ? 未確定

出典は実際に読んだページ。引用はそのままの文言。

| 日本語 | 現状 | 推奨 | 判定 | 根拠 |
|---|---|---|---|---|

**Natalie Walton の語り口は真似しない。** オーストラリアの事務所で、綴りが混在し（favourite と labor）、価格も
平方フィート表示。語彙は使えるが、レジスターは英国式ではない。

**ArchiWest の語彙は大半が対象外。** lath、wattle & daub、period property、Listed Building は英国の
古民家の話で、東京のマンションには出てこない。使えるのは breathability と moisture の筋だけ。

## 3. 使わない語

```
reform            制度改革の意味になる
mansion           豪邸の意味になる
unit bath         和製英語。英語として通じない（註なしでは使わない）
artisan           設計事務所の語彙ではない
luxury / stylish  現状0件。維持する
transform         改修の説明には強すぎる
dream home        同上
```

## 4. 未確定（打ち合わせ後に埋める）

- **検索語** — 在京外国人が実際に何と検索するか。足立さんに「外国人の買い手はどこで探しているか」を聞いてから確定する
- **想定読者** — 在住外国人世帯か、国際結婚世帯か、海外からの買い手か。語彙の難度と前提知識が変わる
- `exclusive floor area` に直すか、`Floor area` のままにするか
- `一級建築士事務所` の説明の付け方

## 5. 現状サイトへの適用（件数）

| 作業 | 件数 | 優先 |
|---|---|---|
| `unit bath` → `prefabricated bathroom` | 10 | **高**（通じない） |

| `built-in joinery` → `bespoke joinery` | 5 | 中 |
| `shikkui` の露出を増やす | 465件中2件のみ | 中 |
| `title` を60字以内に | 81 / 102 | 高（検索結果で切れる） |
| `description` を160字以内に | 78 / 102 | 高（同上） |
