# inbox

父との会話・現場での録音の文字起こし、LINEのやり取り、メモなどを、そのままここに置いてください。
ファイル名・形式は自由です（`.md` / `.txt`）。

置いたら Claude に **「inboxを整理して」** と頼むと、`CLAUDE.md` の手順に従って
`projects/` `decisions/` `materials/` `people/` に振り分けられ、原文は `transcripts/` に保存されます。

## LINEの会話を入れるとき

1. 父とのトークで、残したいやり取りを長押し →「コピー」（複数選ぶときは範囲を選択）
2. このフォルダに `line-YYYY-MM-DD-<話題>.md` という名前でファイルを作って貼り付ける
   - 例：`line-2026-10-31-tojo-yuka.md`
3. **日付の行（`2026/10/31(土)`）も一緒に貼る**。これがないと判断の日付が分からなくなります

電話番号・住所・口座番号などは、整理するときに `［伏字：電話］` のように伏せられます。
